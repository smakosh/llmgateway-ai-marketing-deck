The skills

House style, written down once, reused by every agent.

.claude/skills/blog · #2742

blog

  • Read the docs page and the shipping PR first
  • Pick one primary SEO keyword: title, summary, early paragraph, an H2
  • Frontmatter checked by content-collections
  • gpt-image-2 OG image
  • Never invent prices, limits or quotes
.claude/skills/changelog · Jun 2026

changelog

  • Dated entry in apps/ui/src/content/changelog
  • Confirms plan gating: free, Pro, Enterprise
  • Exact field names and error codes from the code
  • Hands back the OG image prompt
  • Tags + pagination later (#4207)
